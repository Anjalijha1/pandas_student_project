📊 Pandas Student Practice Project
📌 Overview

This project is a beginner-to-intermediate level practice project using Pandas and NumPy.
It covers DataFrame creation, data cleaning, transformation, joins, and basic data analysis operations.

The goal of this project is to strengthen core Pandas concepts by implementing them practically.
